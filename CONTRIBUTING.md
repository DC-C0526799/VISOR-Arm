# Contributing to VISOR Arm

Thank you for your interest in the VISOR Arm project!

VISOR Arm is an AI-powered robotic sorting system developed using the SO-101 robotic arm, Raspberry Pi 5, YOLO object detection, ACT imitation learning, and PLC automation.

## How to Contribute

We welcome suggestions and feedback in the following areas:

- Robotic arm motion optimization
- YOLO object detection improvements
- ACT imitation learning performance
- MQTT and PLC communication
- Raspberry Pi performance optimization
- Fusion 360 mechanical designs
- Technical documentation

## Reporting Issues

If you discover a bug or have an improvement idea, please open a GitHub Issue describing the problem or suggestion.

## Proposing Changes

1. Open an Issue describing your proposed change.
2. Discuss the approach with the project maintainers.
3. Submit a Pull Request for review.
4. Wait for maintainer approval before merging.

## Project Status

VISOR Arm is an ongoing capstone project. Contributions and suggestions are welcome, subject to project maintainer approval and applicable licensing permissions.
