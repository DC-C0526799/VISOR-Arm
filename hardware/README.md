# VISOR Arm — Hardware

This folder documents the hardware components used in the VISOR Arm automated robotic sorting project.

## Main Components

- **SO-101 Robotic Arm:** Performs object pickup and placement.
- **Raspberry Pi 5:** Runs Python-based robotic control and AI software.
- **Feetech STS3215 Servo Motors:** Control the robotic arm joints.
- **USB Cameras:** Provide visual feedback for object detection and robotic manipulation.
- **Hailo-8L AI Accelerator:** Hardware accelerator investigated for AI inference.
- **Allen-Bradley CompactLogix 5380 PLC:** Intended for conveyor and industrial automation integration.
- **Conveyor System:** Transports plastic bottles and aluminium cans to the pickup location.
- **Ultrasonic Sensor:** Detects objects at the conveyor stopping point.
